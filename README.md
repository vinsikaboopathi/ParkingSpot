# ParkingSpot – Smart Parking Reservation

ParkingSpot is a smart parking reservation platform designed to help users find and reserve available parking spaces easily.

## Features

- User registration and login
- Search available parking spaces
- Real-time slot availability
- Parking slot reservation
- QR-based booking verification
- Booking history
- Parking owner dashboard
- Admin management
- Smart parking recommendations
- Peak-hour analysis

## Technology Stack

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MongoDB
